# Remindr

Internal daily-digest dashboard for the platform team.

**Status: the CLI is deprecated.** The product is the web dashboard; all new work goes into `app.py`.

## Quick start
`python app.py --port 8080`, then open http://localhost:8080.

## Structure
- `app.py` — the product.
- `summarize.py` — legacy, to be removed.
- `tests/` — legacy test suite, mostly obsolete.
